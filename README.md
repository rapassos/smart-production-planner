# smart-production-planner
Planejador de produção inteligente

O Planejador de produção inteligente, visa solucionar problemas que normalmente afetam o dia a dia do analista de negócios, chão de fábrica, PCP e Logística, reduzindo o tempo gastocom estas atividades e aumentando a disponibilidade do centro nervoso da producao se preocupar com atividades de mais alto nivel e tomada dedecisoes criticas.

Tecnologia utilizada:
- POO
- Java
- Springboot
- JDBC
- SQL
- API REST

Desejo que este software melhore a sua performance e capacidades de trabalho.
